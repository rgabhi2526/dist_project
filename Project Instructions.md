Course Project Instructions
------------------------------------------------------------------------------------------------------------------------------
As a part of this course, you have to do a project. This project has to be something about developing
and  implementing  a  distributed  algorithm(s).  You  have  two  options  for  this  project:

Option 1: Implement at least two related algorithms – such as algorithms for mutual exclusion/
termination detection/ leader election, etc. You  cannot implement any algorithm that is already
covered or will be covered in the class. So, please avoid all the algorithms discussed in the class
or to be discussed. Specifically, please avoid these topics:

A&M: Chapters 1, 2, 3, 4, 5 (leader election), 6, 7, 9, 10, 14, 15, 16
SG: Chapters 6, 7, 8, 9, 11, 12, 13, 14, 16

Next, you have to develop an application that you can use to test the performance of the algorithms
implemented. You have to compare the performance of the related algorithms implemented.

Note: As mentioned above, the algorithms that you implement have to be related. For instance,
you cannot implement one algorithm for termination detection and the other for mutual exclusion.

Option 2: Develop/Study a new distributed algorithm that is not covered in the literature to show
that the newly developed/studied algorithm is correct. Then, you also have to demonstrate how
this algorithm is better than the algorithms covered so far in literature w.r.t some metrics such as
throughput, latency, etc. You can demonstrate the efficiency of the newly implemented algorithm
either theoretically or through experiments. Note that if you plan to show this theoretically, then
you must have formal proof showing the correctness.

Note: Considering the difficulty of option 2, students choosing option 2 will be given higher marks
as compared to students choosing option 1.

Team Size:

●  Option 1 size <= 2 Choose the existing 2 related algorithms to implement.
●  Option 2 size <= 3 Choose one of the given project problem statements or come up with

your own problem statement.
